# Gia Khang Racing

Bản Việt hoá của **APEX FORMULA 2026**, giữ nguyên gameplay, AI, vật lý xe, đường đua, âm thanh tổng hợp, model xe và tài nguyên đồ hoạ của bản gốc; tên hiển thị được đổi thành **Gia Khang Racing**.

## Chạy local trên Windows
Nhấp đúp `CHAY_GIA_KHANG_RACING.bat`. Game sẽ mở tại `http://127.0.0.1:8341/`.

Không mở `index.html` trực tiếp bằng `file://` vì trình duyệt chặn một số ES Modules/WebGL assets khi chạy theo cách đó.
